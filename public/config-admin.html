通过服务端命令导入 Claude OAuth，完成后在统一上游列表维护模型。

npm run claude:login 生成可共享的本地 fake auth token，并写入 Airouter 配置。
npm run claude:install-login -- --token airouter-oauth-xxx --base-url http://localhost:3009 把本地 fake token 写入 Claude Code 本地凭证；安装前会自动备份原登录态。
