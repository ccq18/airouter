新增 OpenAI token

OpenAI token 只负责 Responses / Codex 兼容链路，是 GPT 主链路。

建议使用浏览器隐私模式登录 ChatGPT 后打开 复制完整 JSON；粘贴后不要退出该登录态，否则 token 会失效。系统会自动提取 accessToken、refresh_token、account id 和邮箱备注。

OpenAI 兼容接口通常填写到 `/v1`。

Claude token

Claude token 只负责 `/v1/messages` 原样转发。请使用命令行登录脚本追加配置。

登录命令
npm run claude:login
脚本会生成本地 fake auth token，并尽量写入 Keychain token SHA-256 以兼容 Claude Code 交互式主请求。

Fallback apikey

apikey 只在对应 token 链路不可用时兜底；不会作为主链路抢占 token。

GPT 兜底通常填写 OpenAI 兼容 `/v1`；Claude 兜底填写 Claude Messages API 的 `/v1`。
